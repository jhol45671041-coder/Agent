What formats are accepted?

• A hosted/remote MCP URL (https://…/mcp or /sse)
• A local stdio command (npx -y …, python server.py, node server.js)
• A GitHub repo link — paste it in the chat instead, and the assistant will install & wire it up.
You can also set TRADINGVIEW_MCP_URL / TRADINGVIEW_MCP_COMMAND environment variables (see .env.example).
